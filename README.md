# Winvinaya Foundation - Monorepo

Welcome to the Winvinaya Foundation development project. This repository is organized as a monorepo containing the mobile application, backend services, and a placeholder for the future web frontend.

## Project Structure

- **[mobile-app/](./mobile-app)**: React Native (Expo) mobile application using React Native Paper, Zustand, and TanStack Query.
- **[Backend/](./Backend)**: FastAPI backend with PostgreSQL, SQLAlchemy (Async), and Alembic for migrations.
- **[frontend/](./frontend)**: Placeholder for the future web frontend.

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- Python (v3.10 or later)
- PostgreSQL
- Expo Go (on your mobile device or emulator)

### Installation & Running

Please refer to the specific `README.md` files within each directory for detailed setup and run instructions:

- [Mobile App Setup](./mobile-app/README.md)
- [Backend Setup](./Backend/README.md)

## Tech Stack

- **Mobile**: Expo, React Router, React Native Paper, Zustand, TanStack Query.
- **Backend**: FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pydantic v2.
